사이트 관리

처음 한 번만 GitHub 열쇠(토큰)를 넣으면 이 기기에서 계속 쓸 수 있어요. 열쇠는 이 기기 안에만 저장되고 다른 곳으로 보내지 않아요.

열쇠 만드는 법 (5분, 한 번만)
  1. github.com 로그인 → 오른쪽 위 사진 → Settings
  2. 맨 아래 Developer settings → Personal access tokens → Fine-grained tokens → Generate new token
  3. 이름: BIUM 사이트 관리 / 만료: 1년
  4. Repository access: Only select repositories → shoesteller-site
  5. Permissions → Repository permissions → Contents: Read and write
  6. Generate token → 나온 글자를 복사해 위 칸에 붙여넣기
