내 이야기를 신다

좋아하는 이야기를 그려 넣은, 세상에 하나뿐인 신발을 만들어 드려요.

좋아하는 걸 제대로 담은 굿즈가 없었다면, 이야기를 들려주세요. 6년 동안 신발에 그림을 그려온 손으로, 당신만의 한 켤레를 그려 드려요.

좋아하는 게 있는데, 그걸 제대로 담은 물건은 없었죠.

좋아하는 캐릭터, 함께 사는 강아지, 잊고 싶지 않은 여행지. 그런데 파는 굿즈는 다 비슷하고, 결국 남이 만든 것에 내 취향을 맞춰 타협하게 돼요.

누구나 자기 이야기를 신고 다닐 자격이 있어요.

좋아하는 걸 담은 물건이 없어 아쉬운 마음, 저도 알아요.

하나뿐인 신발을 받는 세 단계

  1. 1이야기를 들려주세요

    좋아하는 것, 신을 사람, 원하는 분위기를 알려 주세요. 사진 한 장이면 충분해요.

  2. 2시안을 확인하세요

    그리기 전에 시안을 보여 드려요. 마음에 들 때까지 고쳐요. 확인 필요: 시안 수정 횟수

  3. 3하나뿐인 신발을 받으세요

    손으로 그려 마감한 신발을 보내 드려요. 확인 필요: 제작 기간

자주 묻는 질문

주문하면 얼마나 걸리나요?

확인 필요: 기존 디자인·개인 디자인 제작 기간

그림 실력이 없어도 개인 디자인 주문이 되나요?

네. 이야기와 사진만 주시면 시안은 저희가 그려요.

어떤 신발에 그리나요?

흰 캔버스 운동화를 기준으로 해요. 확인 필요: 가능한 소재, 내 신발 보내기 가능 여부

물감이 벗겨지지 않나요?

수업에서는 자투리 시편에 먼저 칠해 문지르고 긁고 구부려 봐요. 물감 테스트 결과는 영상으로 공개하며, 내구성을 보장한다고 약속하지 않아요. 건조가 끝나기 전 결과는 그렇다고 표기해요.

세탁과 관리는 어떻게 하나요?

확인 필요: 세탁 방법·관리법
